# Alborz Filing Monitor

## Requirements

- Python 3.11+
- Git
- Internet

---

## Installation

Run:

install.bat

---

## Start

Run:

run.bat

---

## Folder Structure

project/

auth/

daily/

logs/

state/

config.json

main.py

---

## Daily Files

Files are saved in:

daily/

Example:

1405-05-04.json

1405-05-05.json

---

## Auto Update

The monitor checks every 5 minutes.

New properties are added automatically.

Updated properties are replaced automatically.

---

## Git

If enabled:

git add

git commit

git push

are executed automatically.

---

## Logs

All logs are stored in:

logs/

---

## Stop

Press:

CTRL + C
